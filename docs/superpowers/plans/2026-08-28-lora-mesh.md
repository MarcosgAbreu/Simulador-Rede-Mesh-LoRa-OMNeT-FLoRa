# Rede mesh LoRa com IDE Python Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Construir no WSL2 um cenário OMNeT++/FLoRa de mesh LoRa parametrizável por uma GUI Python, com logs JSONL reproduzíveis, relatório e vídeo MPEG com 300 ms por evento.

**Architecture:** Um projeto local conterá um instalador idempotente, um modelo OMNeT++ que implementa vizinhança e encaminhamento multi-hop sobre o rádio do FLoRa/INET, e uma camada Python que valida parâmetros, executa o simulador e renderiza os eventos. O trio de dependências será OMNeT++ 6.4.0, INET 4.6.0 e FLoRa 1.3.0, mantendo a versão do INET alinhada à compatibilidade publicada pelo FLoRa.

**Tech Stack:** Bash, OMNeT++/NED/C++, INET, FLoRa, Python 3, Tkinter, JSON Lines, Matplotlib/Pillow e FFmpeg MPEG-2.

## Global Constraints

- O projeto deve executar no WSL2 Ubuntu e não depender de caminhos fixos fora do diretório do projeto.
- A área padrão é `1000 x 1000 m`.
- A ativação padrão é uniforme entre `0` e `3600 s`.
- O tempo máximo simulado padrão é `14400 s`.
- Os nodos são estáticos e não possuem limitação de energia.
- A configuração de rádio usa AU915, canais de 125 kHz, SF7–SF12 e potência de transmissão de 14 dBm.
- A mesh é uma extensão customizada sobre FLoRa; ela não será descrita como LoRaWAN padrão.
- O log principal é `events.jsonl`, uma linha JSON por evento.
- Cada evento renderizado permanece por `300 ms`.
- O vídeo final usa contêiner MPEG (`.mpg`) com codificação MPEG-2.
- A mesma semente e os mesmos parâmetros devem produzir posições e ativações reproduzíveis.
- Não criar commits automaticamente; o workspace só será versionado se o usuário solicitar.

        {"event": "PACKET_DROPPED", "drop_reason": "TTL_EXPIRED"},
    ])

    assert report["packets_delivered"] == 1
    assert report["packets_dropped"] == 1
    assert report["delivery_rate"] == 0.5
